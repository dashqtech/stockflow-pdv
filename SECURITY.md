# Segurança

Este repositório contém apenas documentação e imagens de portfólio. Não há código executável, instalador, credenciais ou configuração do ambiente da loja.

Se alguma imagem ou documento expuser um dado que não deveria estar público, use o reporte privado de vulnerabilidade na aba Security do GitHub. Não coloque dados pessoais ou informações que permitam explorar um problema em uma issue aberta.
